一代人有一代人的打字通
想到让孩子开始打字，尝试搜索，我最先想到的就是金山打字通
奈何过去了太久，金山打字通已经没有更新，字体很小，内容也跟不上
所以干脆手搓一个字体放大版的，结合小学人教版教材要掌握的词语和单词
让孩子学了拼音和英语有一个新的使用场景去熟悉指法
加了按孩子兴趣生成短文，短文中学几个单词
加了桌宠功能让孩子找个小伙伴
加了游戏小功能，逐步从打字母过渡到打词组
后续继续完善积分兑换功能，和孩子共同设定目标逐步完成
后续继续增加课内古诗词、英语power up，KET,PET词汇
希望能得到大家的反馈
